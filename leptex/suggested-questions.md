# Welcome message and suggested questions

Paste into **Web link → Appearance**.

## Welcome message

> Hi — what would you like today?

The site's headline asks *"What would you like today?"*. The default welcome,
*"Hi! How can I help you today?"*, drops from selling back to support in the
space of one click. Echoing the headline keeps the handoff seamless: the visitor
is answering the same question they were already reading.

## Suggested questions

These are shown to a visitor who arrives with no question pre-filled — usually
from the header button or the floating pill, not from a question card. Order
them by how close each sits to a purchase.

```
How do I place an order?
What are today's prices?
Do you still have hawthorn?
```

The third one catches the seasonal announcement on the site. **Whatever the
banner is shouting, the landing page should ask about first.**

Both fields are auto-translated by Leptex, so write them in one language only.
